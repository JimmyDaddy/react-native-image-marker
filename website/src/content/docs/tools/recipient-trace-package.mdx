## Keep the mapping protected

Recipient IDs are written only to `recipient-mapping.json`; image pixels contain random locators. The ZIP does not include the key. A browser run is limited to 30 recipients. Move the mapping into your protected audit store, apply an appropriate retention policy, and perform production embedding in a trusted service.
