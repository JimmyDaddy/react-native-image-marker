## Choose what you want to add

<div class="principles-grid">
  <article class="principle">
    <strong>
      <code>Marker.markText</code>
    </strong>
    <p>
      Add one or more text layers. Adjust the font, outline, background, angle,
      position, or tiled layout.
    </p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.markImage</code>
    </strong>
    <p>Add one logo, QR code, or icon—or repeat it in a staggered pattern.</p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.mark</code>
    </strong>
    <p>
      Add text and images together, choose their order, and blend them naturally
      into the photo.
    </p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.createRecipe</code>
    </strong>
    <p>
      Process a batch with per-image text, conditional layers, progress, and
      cancellation.
    </p>
  </article>
  <article class="principle">
    <strong>
      <code>embedInvisible / detectInvisible</code>
    </strong>
    <p>
      Write a short authenticated trace ID into the pixels, then recover it
      after distribution.
    </p>
  </article>
  <a
    class="principle principle-link"
    href="/playground/?workflow=editor#editor-playground"
  >
    <strong>
      <code>ImageMarkerEditor</code>
      <span>Optional package</span>
    </strong>
    <p>
      Multi-select, group, align, resize, rotate, and organize Recipe v2 layers
      before rendering them through Core 2.1.
    </p>
  </a>
</div>

Everything runs on the device or in the browser. There is no account to create and no image upload. When you add several watermarks, items later in the list appear on top.

[Use an online image tool](/tools/), [try the live Web SDK](/playground/), or
[read the standalone Web SDK guide](/guides/web-sdk/). You can also [install Core](/getting-started/). For shared workflows, start with the
[Recipe document](/recipe/), [Node renderer](/node/), or [CLI](/cli/).
