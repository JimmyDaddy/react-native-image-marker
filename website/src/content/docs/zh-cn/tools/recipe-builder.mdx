## 数据驱动、可复用

Recipe 可以保存文字模板、有序文字和图片图层、条件显示、输出格式、质量与画布设置。图片资源不要直接塞进 JSON，而应在运行时注入可信来源。导入的 JSON 会先经过 SDK 验证再渲染。
