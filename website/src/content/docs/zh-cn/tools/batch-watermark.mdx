## 本地批处理

Recipe API 会保持输入顺序、隔离单项失败、报告进度，并在停止后跳过尚未开始的项目。一次本地任务最多选择 20 张、总计 80 MB；更大的文件或带机密密钥的生产任务应放在自己的鉴权服务中。
