## 保护好映射表

收件人标识只写在 `recipient-mapping.json` 中，图片像素里只有随机 locator，ZIP 也不包含密钥。浏览器一次最多处理 30 个收件人。请把映射表移入受保护的审计存储，设置合适的保留周期，并在生产环境的可信服务中完成嵌入。
