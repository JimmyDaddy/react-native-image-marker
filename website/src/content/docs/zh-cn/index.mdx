## 按照要添加的内容选择方法

<div class="principles-grid">
  <article class="principle">
    <strong>
      <code>Marker.markText</code>
    </strong>
    <p>
      添加一个或多个文字图层，并调整字体、描边、背景、角度、位置或平铺方式。
    </p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.markImage</code>
    </strong>
    <p>放置一个 Logo、二维码或图标，也可以通过错行排列铺满整张照片。</p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.mark</code>
    </strong>
    <p>同时添加文字和图片，决定图层顺序，并让水印自然融入照片。</p>
  </article>
  <article class="principle">
    <strong>
      <code>Marker.createRecipe</code>
    </strong>
    <p>
      用一套配方批量处理图片，并为每张图注入文字、控制图层、查看进度或取消任务。
    </p>
  </article>
  <article class="principle">
    <strong>
      <code>embedInvisible / detectInvisible</code>
    </strong>
    <p>把经过认证的短追踪 ID 写入像素，在素材分发后再恢复并验证。</p>
  </article>
</div>

所有处理都在设备或浏览器中完成，不需要账号，也不会上传图片。添加多个水印时，列表中靠后的内容会显示在上面。

[直接使用在线图片工具](/zh-cn/tools/)、[在线运行 Web SDK](/zh-cn/playground/)、[安装此库](/zh-cn/getting-started/)，或阅读[隐形追踪水印指南](/zh-cn/guides/invisible-watermarks/)。
