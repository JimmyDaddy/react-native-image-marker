# RFC 0002：v1.9 跨平台图层混合模式

- 状态：Accepted
- 目标版本：v1.9
- 适用平台：iOS、Android、Web

## 背景

现有文字和图片水印只使用普通 alpha 合成。签名、纸张纹理、扫描件和摄影 Logo 常需要 multiply、screen 或 overlay 等混合方式，才能自然地与底图融合。

Web Canvas、Core Graphics 和 Android Canvas 都有图层合成能力，但各自支持的全集并不相同。本 RFC 只公开六个能够稳定映射到三端的模式。

## 目标

1. 文字与图片水印使用同一套混合模式名称。
2. alpha、平铺、旋转、描边与混合模式可以组合。
3. 每个图层的绘制状态在结束后恢复，不影响后续图层。
4. 未设置时保持现有普通合成结果。

## 非目标

- 不为背景图增加混合模式。
- 不公开 mask、destination-in 等会改变整个画布语义的合成操作。
- 不保证不同图形引擎逐像素完全相同；使用容差式像素测试。
- 不在 v1.9 增加滤镜、调色或通用图片编辑 API。

## 公共 API

```ts
type BlendMode =
  | 'normal'
  | 'multiply'
  | 'screen'
  | 'overlay'
  | 'darken'
  | 'lighten';

interface TextOptions {
  blendMode?: BlendMode;
}

interface WatermarkImageOptions {
  blendMode?: BlendMode;
}
```

默认值为 `normal`。`ImageOptions` 不包含该字段，因此背景图不能配置混合模式。

## 平台映射

| API      | Web Canvas  | iOS Core Graphics | Android Canvas |
| -------- | ----------- | ----------------- | -------------- |
| normal   | source-over | normal            | SRC_OVER       |
| multiply | multiply    | multiply          | MULTIPLY       |
| screen   | screen      | screen            | SCREEN         |
| overlay  | overlay     | overlay           | OVERLAY        |
| darken   | darken      | darken            | DARKEN         |
| lighten  | lighten     | lighten           | LIGHTEN        |

Android 使用与最低支持 API 兼容的 `PorterDuffXfermode`，避免把最低系统版本提升到只支持 `BlendMode` 的版本。

## 绘制语义

1. `alpha` 先作用于完整水印图层，再按 `blendMode` 与已有画布合成。
2. 平铺图层的所有副本共享同一个 alpha 与 blend mode。
3. 文字的填充、描边、阴影与背景属于同一个逻辑图层，使用同一 blend mode。
4. 每层绘制前保存上下文，结束后恢复；失败路径也必须恢复状态。
5. recipe 不需要特殊处理，blend mode 作为静态图层字段被保留并渲染。

## 校验与错误

- JavaScript 在调用 bridge 前拒绝未知模式。
- iOS 与 Android 仍独立校验，防止调用方绕过 JavaScript。
- 错误路径必须指出具体图层，例如 `watermarks[1].blendMode`。

## 兼容性

- 字段可选且默认 `normal`，现有调用输出不变。
- 不修改方法签名，只扩展嵌套图层参数。
- Expo Go 的限制不变；安装含 native 修改的 v1.9 后需要 development build 或重新执行原生构建。

## 测试计划

- TypeScript 与 JavaScript 枚举校验。
- Web：验证 `globalCompositeOperation` 设置、恢复及失败路径。
- iOS：解析映射、上下文状态恢复和容差式像素测试。
- Android：解析映射、Paint 状态恢复和 API 24/31 仪器测试。
- 组合：alpha、平铺、旋转、文字描边、混合图层顺序。
- Playground：每种模式可切换，并提供 multiply 与 screen 的高对比示例。

## 发布策略

与 RFC 0001 的数据驱动配方合并为一次 v1.9.0 minor release。首版只包含表中六种模式；新增模式需要先证明三端映射与像素测试稳定。
